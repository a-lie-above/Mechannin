# Mechannin
A simple (hopefully) difficult Shmup game 

This game is based on Undertale/Deltarune's battle system in a shmup style game, which Undertale/Deltarune is inspired by TouHou, which is- Wait is this just TouHou?

I don't know, probably not, anyways, I made this game for fun.

Controls are only arrow keys and WASD.

7 waves, only one Hp.

This game is (probably) VERY difficult! So you've been warned.
